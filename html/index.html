Quick start

1

Install

Add to your module: go get github.com/boracomet/go-irmik

go get github.com/boracomet/go-irmik
2

Write

Create a router with irmik.New; define a route.

app := irmik.New()
app.GET("/", home)
3

Run

go run main.go, default :8080

go run main.go
# → :8080
